# Reproducing the paper

The folder [code_paper](https://github.com/QihuangZhang/CeLEry/tree/main/code_paper) of the repository contains the analysis code of the paper:

Zhang, Q., Jiang, S., Schroeder, A., Hu, J., Li, K., Zhang, B., Dai, D., Lee, E. B., Xiao, R. and Li, M. Leveraging spatial transcriptomics data to recover cell locations in single-cell RNA-seq with CeLEry. *Nature Communications* **14**, 4050 (2023). [https://doi.org/10.1038/s41467-023-39895-3](https://doi.org/10.1038/s41467-023-39895-3)

Each row gives the Results subsection of the paper that a folder belongs to, with its title as published, and the figures that the folder supports. The figure numbers refer to the published article and its Supplementary Information. The README in each folder describes the steps and the output of each script.

Two Results subsections have no folder. "Overview of CeLEry" presents the workflow of Fig. 1. The tutorial [Data augmentation](tutorials/augmentation.md) runs the data augmentation of the paper on data that are in the repository.

## Running the code

- The scripts and notebooks were written for the software environment of 2022 to 2023. The notebooks that record a Python version name 3.8 or 3.9. Several files call functions that the current package does not provide: `cel.SpaCluster` in `1_LIBD`, `2_Alzheimer` and `8_mouse_single_cell_prediction`, `cel.DNNordinal_v1` in `2_Alzheimer` and `cel.DataAugmentation2` in `7_data_augmentation`. The notebooks of `3_Mouse_10x_Visium` call `cel.get_SSIM`, which raises a `ValueError` with current scikit-image releases. [RENOVATION_LOG.md](https://github.com/QihuangZhang/CeLEry/blob/main/RENOVATION_LOG.md) describes the known breaks of the package.
- The paths inside the code are hard-coded and must be edited before a run. They point to the authors' computing cluster, to folders relative to the authors' working directory (such as `../data`, `../output`, `data` and `output`), or to empty strings (`os.chdir("")` in `6_breast_cancer_10x_Xenium`).
- The code in these folders is not part of the package tests. The [tests](https://github.com/QihuangZhang/CeLEry/tree/main/tests) do not run it, so a change to the package is not checked against it.

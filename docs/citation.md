# Citation

If you use CeLEry in your research, please cite the paper:

> Zhang Q, Jiang S, Schroeder A, Hu J, Li K, Zhang B, Dai D, Lee EB, Xiao R, Li M. Leveraging spatial transcriptomics data to recover cell locations in single-cell RNA-seq with CeLEry. *Nature Communications* **14**, 4050 (2023). <https://doi.org/10.1038/s41467-023-39895-3>

GitHub's "Cite this repository" button uses the [`CITATION.cff`](https://github.com/QihuangZhang/CeLEry/blob/main/CITATION.cff) file of the repository.
